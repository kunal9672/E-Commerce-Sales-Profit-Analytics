# E-Commerce Sales & Profit Analytics

This project focuses on analyzing e-commerce sales and profitability to understand business performance across products, categories, cities, payment modes, order status, and monthly trends.

The project covers data cleaning, SQL-based analysis, and interactive Power BI visualization using a structured analytics workflow.

## Tools Used

- Excel
- Python
- Pandas
- NumPy
- MySQL
- SQL
- Power BI

## Analysis

The project looks at:

- Sales and profit performance
- Order volume and average order value
- Product and category performance
- City-wise sales
- Payment mode usage
- Order status
- Monthly sales and profit trends

## Dashboard

The Power BI dashboard presents key business metrics through KPI cards, charts, slicers, and filters.

It helps explore sales and profitability across different business dimensions and identify areas of strong and weak performance.

## Project Workflow

Excel → Python → MySQL → SQL → Power BI

## Project Files

- `data` – Source Excel file and cleaned CSV
- `python` – Data cleaning notebook
- `sql` – SQL analysis queries
- `powerbi` – Power BI dashboard
- `screenshots` – Dashboard screenshots
